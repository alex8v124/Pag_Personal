# **App Name**: Personal Showcase

## Core Features:

- Introduction Section: Display a personal introduction with name, a brief biography, location and contact information.
- Featured Projects Section: Showcase key projects and works with descriptions and links. Utilize a gallery layout to highlight each project.
- Skills List: Enumerate technical skills in categories like Programming Languages, Frameworks, Databases, etc.
- Social Links: Provide direct links to social media profiles and online portfolios such as GitHub and LinkedIn.
- Image Generation: Generative AI tool to allow users to upload existing picture or provide search terms which will determine what profile picture gets associated with your details.  

## Style Guidelines:

- Primary color: Soft gray (#A9A9A9) for a modern and neutral look.
- Background color: Very light gray (#F5F5F5) to maintain a clean and airy feel.
- Accent color: Muted blue (#778899) to add a subtle touch of sophistication to interactive elements and links.
- Body and headline font: 'Inter', a grotesque-style sans-serif, to ensure readability and a modern, machined, objective, neutral feel.
- Use a clean, responsive grid layout optimized for both desktop and mobile devices.
- Use minimalist icons for navigation and social media links.
- Incorporate subtle transition animations on interactive elements like buttons and links to enhance user engagement.
